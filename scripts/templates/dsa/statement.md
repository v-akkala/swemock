Given an array of integers `nums` with at least two elements, return the sum of its two largest values. If the largest value appears more than once, each copy counts separately.

## Examples

**Example 1**

```
Input:  nums = [3, 9, 4]
Output: 13
```

The two largest values are $9$ and $4$.

**Example 2**

```
Input:  nums = [5, 5, -1]
Output: 10
```

## Constraints

- $2 \le \text{nums.length} \le 10^5$
- $-10^9 \le \text{nums}[i] \le 10^9$
