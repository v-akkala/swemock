Entries can now expire. `put(key, value, ttl=None)` takes an optional time-to-live in seconds; the entry is treated as absent once `ttl` seconds have passed since it was stored (the clock is injected: `LRUCache(capacity, clock)`, where `clock()` returns the current time in seconds, defaulting to `time.monotonic` in Python and to a function you must be given in C++). An expired entry is never returned by `get`, is not counted by `size()`, does not appear in `keys()`, and never causes a live entry to be evicted while an expired one is still present. Replacing a key resets its ttl (a `put` without `ttl` makes the entry permanent).
