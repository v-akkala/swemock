Tasks can now be cancelled. `cancel(task_id)` cancels a task that is `waiting` or `ready`, **and every task that depends on it, directly or indirectly**, and returns the list of ids it cancelled in the order the tasks were added. A cancelled task has the status `cancelled`, is never returned by `next_task`, and never blocks anything else from running (its dependents are cancelled with it). Cancelling a `running` or `done` task, an already cancelled task, or an unknown id raises `ValueError` (C++: `std::invalid_argument`).
